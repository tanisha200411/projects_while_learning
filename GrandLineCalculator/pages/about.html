📜 About Grand Line Adventure

An interactive One Piece pirate navigation web suite built for navigators and fans across the seas.

🚀 Tech Stack

• Frontend: HTML5, Vanilla CSS3, JavaScript (ES6+)
• Backend: Python Flask REST APIs
• Database: SQLite database (`database.db`)
• Graphics & Audio: HTML5 Canvas 3D Log Pose engine & Web Audio API synthesizer

🧭 Log Pose Navigation Concept

Standard compasses fail in the Grand Line due to localized magnetic forces. A Log Pose is a spherical compass that records an island's magnetic signature to guide sailors to their next destination.
