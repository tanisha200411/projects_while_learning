# ☠ One Piece Adventure Website 🌊

A creative fan-made **One Piece themed interactive website** inspired by the world of pirates, adventures, islands, and legendary characters.

## 🚢 About The Project

One Piece Adventure is a frontend web project designed to bring the feeling of exploring the **Grand Line** into a modern website experience.

The website includes a pirate-themed UI, animated elements, character showcases, devil fruit information, and interactive adventure sections.

## ✨ Features

- 🌊 One Piece inspired design
- ☠ Pirate themed navigation
- 🏴‍☠️ Straw Hat Pirates showcase
- 🍎 Devil Fruit explorer
- 🗺 Grand Line island map
- ⚔ Character information cards
- 🎨 Smooth animations and effects
- 📱 Responsive design

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
